# Worked setup: an archive becomes a media pilot

This fictional exercise connects to Lesson 1. It uses no private instructor archive and requires no external publishing accounts.

1. Copy the six files in `company-template` to your own company folder.
2. Replace that copy's `COMPANY.md`, `PROJECT.md`, and `TASK.md` with the three files beside this README. Keep `TEAM.md`, `AGENTS.md`, and `SKILL.md` from the template.
3. Give the assistant all six files and say: “Read the company files and run the first pilot task as Foreman. Use only the fictional source notes. Produce drafts and report the review arrangement.”
4. Have a separate conversation or person inspect the output against `TASK.md`. If that is unavailable, label the review as self-review and leave independent acceptance pending.

Expected outputs are `output/pilot-brief.md` and `output/sample-script.md`. These are assignments, not files shipped pre-completed. If your host cannot create files, save its returned text at those paths yourself and ask the reviewer to inspect the saved copies.

There is no single correct creative answer. A successful run uses the existing notes, proposes one useful pilot for the stated audience, produces the two artifacts, and exposes any missing evidence. Publishing a site, buying a domain, building a bot roster, and producing finished video are outside this exercise.
