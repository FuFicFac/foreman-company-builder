# Buzz Academy

Buzz Academy is a Foreman Company package for teaching people to use Buzz from zero through a completed, evidence-backed multi-agent workflow.

It turns a learner's real starting point into a guided path: identity safety, workspace fluency, agent setup, threaded collaboration, a shipped artifact, and a closeout report.

> Learn Buzz by shipping one real result with a small accountable agent team.

## First Useful Run

```text
Intake -> identity safety -> workspace orientation -> one agent task -> one multi-agent handoff -> shipped artifact -> verified closeout
```

The company does not promise total automation or force every learner through every feature. It finds the learner's current stage, teaches the next useful move, and requires evidence before progression.

## Package Files

- `COMPANY.md` — promise, scope, rules, and definition of done.
- `TEAM.md` — responsible operator and specialist roles.
- `WORKFLOWS.md` — staged learning and delivery workflows.
- `APPROVAL_GATES.md` — human decisions and irreversible-action boundaries.
- `HEARTBEAT.md` — learner progress and operating reports.
- `COMPOSITION.json` — selected Foreman departments, capabilities, gates, and evidence.
- `workspace-template/README.md` — starter workspace for one learner or cohort.

## Operating Modes

Hermes-only mode uses a local workspace, Hermes tools/skills, and Foreman closeout. Paperclip-board mode adds visible issues, roles, evidence, and progress while Hermes still performs the work and Foreman verifies it.
