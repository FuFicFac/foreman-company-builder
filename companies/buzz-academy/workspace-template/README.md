# Buzz Academy Learner Workspace

Use one workspace per learner or bounded cohort run.

```text
README.md
intake/
  learner-goal.md
  current-state.md
plan/
  acceptance-criteria.md
  workflow.md
artifacts/
evidence/
  inspection-verdict.md
  approval-record.md
reports/
  closeout.md
```

Do not store private keys, recovery phrases, provider secrets, or copied credentials here.

A run starts only after `learner-goal.md` and `acceptance-criteria.md` are agreed. A run closes only when the artifact is in `artifacts/`, evidence is in `evidence/`, and `reports/closeout.md` names the outcome, checks, defects, and next step.
