# WORKFLOWS.md — Buzz Academy

## Universal Intake

1. Ask what the learner wants to accomplish.
2. Inspect the current Buzz state and available artifacts without requesting secrets.
3. Infer the learner's stage.
4. Confirm the stage and one bounded outcome.
5. Select only the lessons needed to ship that outcome.
6. Define acceptance evidence before work begins.

## Stage Map

### Stage 1 — Identity Safety
Exit evidence: learner can identify the active identity, confirms a backup posture, and states what must never be shared.

### Stage 2 — Workspace Fluency
Exit evidence: learner creates or selects the correct channel/thread and can explain where the conversation context belongs.

### Stage 3 — First Agent Result
Exit evidence: one bounded task, one named owner, explicit acceptance criteria, and a readable artifact.

### Stage 4 — Multi-Agent Handoff
Exit evidence: a planner/builder/inspector split or equivalent, thread-correct handoff, and no duplicate ownership.

### Stage 5 — Ship And Verify
Exit evidence: artifact path or URL, checks performed, defects routed, and human approval for any public action.

### Stage 6 — Closeout And Repeat
Exit evidence: short learner report, reusable next-step workflow, and explicit unresolved risks.

## Core Workflow

```text
Intake -> stage confirmation -> safety check -> bounded task -> build -> independent inspect -> human gate if needed -> ship -> closeout
```

## Recovery Workflow

```text
Observe failure -> preserve evidence -> classify workspace/runtime/model/memory/tool/delivery layer -> run the smallest diagnostic -> repair -> repeat acceptance check -> report honestly
```

## First Tester Workflow

One 30–45 minute guided run should produce one real artifact. Do not teach every Buzz surface. Prove identity safety, correct threading, one useful agent result, and evidence-backed closeout.
